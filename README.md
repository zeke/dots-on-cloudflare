# dots-on-cloudflare

An exploration of how to build an always-on personal agent, similar to OpenAI's dots, on Cloudflare. Each person gets one long-lived agent that owns ongoing work, has its own sandboxed computer and browser, connects to MCP servers and tools like GitHub, and can be reached through web chat, messaging, or voice.

It started as a way to give people at Cloudflare something like dots while working within the company's controls. It may also become an open source project anyone can deploy to their own Cloudflare account.

Nothing is built yet. See [PLAN.md](PLAN.md) for the current thinking, and [AGENTS.md](AGENTS.md) for notes aimed at coding agents.
